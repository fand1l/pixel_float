# Pixel Float

Оверлей навколо вирізу камери, що показує вхідні сповіщення.
Особистий застосунок під один пристрій: Pixel 9 Pro, Android 17.

Архітектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Поточний стан: етап 1a — перевірка вікна

Що вже є:

* Каркас збірки: AGP 9.3.1, Gradle 9.5.1, Kotlin 2.3.21, KSP 2.3.11,
  compileSdk/targetSdk 37, minSdk 36; Compose + Material 3, Room, DataStore.
* Вікно `TYPE_APPLICATION_OVERLAY` з однією статичною пігулкою, власним
  життєвим циклом для Compose і областю дотиків лише на самій пігулці.
* Обидві служби оголошені (слухач сповіщень і accessibility) — поки без логіки,
  але видно, чи вони прив'язані.
* Діагностика без adb: кільцевий журнал у пам'яті + запис у Room, збереження
  останнього падіння, лічильник кадрів.
* GitHub Actions: debug APK в артефактах і в rolling prerelease `latest`.

Чого ще немає: сповіщень, черги, анімації, жестів, калібрування, історії.

## Встановлення з телефона

Порядок важливий — кожен крок блокує наступний.

1. **Дозволити встановлення з браузера.** Відкрийте сторінку релізу `latest`
   у браузері; на першій спробі Android попросить дозвіл «Встановлення
   невідомих застосунків» для цього браузера.
2. **Встановити APK.**
3. **Зняти обмеження.** Налаштування → Застосунки → Pixel Float → ⋮ →
   **Дозволити обмежені налаштування**. Без цього перемикачі доступу до
   сповіщень і accessibility будуть неактивні: Android блокує їх для APK,
   встановлених поза Play. Це не помилка застосунку.
4. **Дозволи.** У самому застосунку: «Поверх інших застосунків» (потрібен уже
   на етапі 1a), далі — доступ до сповіщень і accessibility (знадобляться
   на етапах 1b і 2).

## Що перевіряє етап 1a

Відкрийте застосунок і натисніть «Показати острівець».

1. **Вікно з'являється?** Лічильник `frames` має бути > 0. Нуль при
   `attached: true` означає, що композиція не отримала жодного кадру.
2. **Пігулка там, де треба?** Повзунки рухають її; значення зберігаються
   в DataStore і застосовуються до вікна без перезапуску.
3. **Дотики не зламані?** Торкніться екрана поруч із пігулкою і потягніть
   униз — шторка має відкритися. Тап по самій пігулці ховає її.
4. **Що каже система про виріз?** Блок «Виріз екрана» показує
   `boundingRects`, `safeInsetTop`, щільність і поворот — це вихідні дані
   для калібрування на етапі 1b.

Якщо щось не так — знімок журналу з екрана застосунку відповідає на питання
«не з'явилось» / «не прив'язалось» / «виняток проковтнуто».

## Збірка

Локальне середовище не потрібне: усе збирає GitHub Actions на кожен push.
APK лежить в артефактах збірки і в пререлізі `latest`.

### Ключ підпису

`keystore/debug.keystore` закомічений **навмисно**. Це debug-ключ, не реліз:
без фіксованого ключа кожна збірка підписується новим сертифікатом, Android
відмовляється оновлювати застосунок поверх, і кожне оновлення вимагає
видалення — з утратою бази, налаштувань, калібрування і **обох дозволів**.

**Ніколи не перегенеровуйте цей файл** і не додавайте `applicationIdSuffix`
для debug: дозвіл слухача сповіщень прив'язаний до `ComponentName`.

### Версії

`gradle/libs.versions.toml` — єдине місце з версіями. Два обмеження, які легко
порушити:

* **Kotlin пінується під KSP, а не навпаки.** Найновіший KSP — 2.3.11; версії
  під Kotlin 2.4 не існує, а Room працює через KSP. Тому Kotlin 2.3.21.
* **AGP 9 має вбудований Kotlin.** Плагін `org.jetbrains.kotlin.android` не
  застосовується; підняти KGP/KSP можна лише через `buildscript` classpath у
  кореневому `build.gradle.kts` — літерали там мусять збігатися з каталогом.
